# Release verification

Verified locally on 15 November 2026 using a Mac with Apple Silicon. This record describes engineering checks of version 0.1.0, not proof of learning effectiveness or a certification of security.

| Pedidos example                          | 5 runnable tests for creation, validation, transaction rollback, event processing and repeated delivery                                                                                                                                         | Passed                                                  |

The native file picker response is simulated in the automated desktop test; the menu and preload bridge are real, and the selected synthetic directory is read by the packaged engine. A separate manual check opened the real macOS folder picker and imported the chosen example directory. Full manual accessibility testing and fresh-machine installation remain necessary before a stable release.

The GitHub adapter is tested against synthetic authenticated API responses and a public repository. Access to a real organization's private repository, including SSO or token policies, has not been validated. The model adapter is tested through an actual local HTTP exchange with controlled responses, including changed-provider rejection. A live third-party or installed language model has not been used to establish response quality.

The 38 backend tests comprise 13 core tests, 17 ChatGPT connection tests and 8 graph projection tests. The packaged Apple Silicon application also passed its desktop test. ZIP and DMG integrity checks and strict verification of the application's complete ad-hoc signature passed locally. The app does not have an Apple Developer ID identity or notarization. Startup on the development Mac does not establish Gatekeeper acceptance of a downloaded copy on another Mac.

The ChatGPT protocol tests use generated RSA identities, injected encryption and controlled provider responses. They exercise local callback handling and the application request path without signing into a real account. The packaged desktop test separately initialized real Electron `safeStorage`, checked the encrypted local registration file and its owner-only permissions, and exercised the external-link restrictions with the browser launcher intercepted. Real-account sign-in, account eligibility, model availability, native credential persistence across signed app updates, and allowance consumption have not been verified. Prebuilt downloads remain pending publication; the public installation instructions use the source checkout.

Source declarations, inferred relationships and self-assessment retain their documented limits. The tests establish that evidence is located and recorded as designed; they do not establish that every proposed explanation is correct or that a learner can transfer the knowledge independently.

## Large-capture exploration

Eight graph tests cover aggregation and original evidence, cycles, direction and depth, scoped source collections, deterministic paging, isolated and late files, and retaining a high-degree focus file on every page. A synthetic fixture with 4,000 file nodes and 24,000 directed dependencies exercised four bounded projections in roughly 45–65 ms on the development Mac. This is a local synthetic timing, not a latency promise or evidence of semantic accuracy.

The browser suite includes a synthetic 4,000-file snapshot: finding file 3,999, selecting directed one- and two-hop neighborhoods, and paging an accessible list of 40 directory groups. The original source, practice, save recovery and account flows remain in the suite. Real multi-repository behavior, language-server indexes, runtime traces and user comprehension outcomes are outside this validation.

## Reproduce

Use Node.js 24 or later. See [contributing](../CONTRIBUTING.md) for the browser checks and [Mac build workflow](../.github/workflows/macos.yml) for the packaged test and checksums. The [CI workflow](../.github/workflows/ci.yml) checks the application on macOS and Linux. Public deployment follows a successful main-branch CI run.
