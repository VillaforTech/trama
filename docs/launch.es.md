# Texto para compartir Trama

Estoy construyendo Trama para algo que me pasa al trabajar con código ajeno o generado con IA. Puedo leer una explicación y sentir que la entendí, pero después me cuesta reconstruir el recorrido o explicar qué cambiaría en otra situación.

Trama es una aplicación para Mac. Abres una carpeta y organiza una ruta desde su arquitectura hasta sus procesos y conecta cada paso con el código. Puedes escribir una predicción, contrastarla con las fuentes y practicar una variante. El trabajo queda guardado para retomarlo después.

La aplicación se ejecuta en tu Mac y permite estudiar repositorios privados. Incluye ejemplos para probar el recorrido y una conexión opcional a modelos locales o compatibles con OpenAI.

Publiqué el código para que puedan usarlo, revisarlo y contribuir. Si lo pruebas, me interesa saber en qué parte de tu proyecto te ayudó y dónde la ruta se quedó corta.
