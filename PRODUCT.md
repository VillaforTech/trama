# Trama

Trama helps people learn how a codebase works through its architecture, features, processes and source evidence. The first audience is developers maintaining a repository they did not fully write or understand, including private repositories and code generated with AI.

The core task is to open a project, choose a behavior, predict what happens, read the relevant implementation and explain a new variant. A saved revision and notebook make the work resumable. The public examples demonstrate this workflow before installation.

The product is a Mac desktop application built with Electron, a React interface, an isolated local Node.js service and SQLite. A browser preview provides only fictional examples. Optional model connections can produce explanations with validated source locations. Model interpretation and self-assessment remain visible as such.

The interface defaults to Spanish. Public contribution documentation is available in English and Spanish. The installed application's code and learning data stay in the user's local store until the user exports them or requests a model consultation.

The original graphite and lime visual identity uses a persistent library, compact project navigation, a structural view of dependencies and progressively revealed study tasks. The primary action is opening a project. Additional controls live in their task context.
