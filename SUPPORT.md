# Getting help

Start with the [five-minute walkthrough](docs/getting-started.md), [installation instructions](README.md#install-on-mac), and [known scope](README.md#evidence-and-scope). The interface currently uses Spanish; English and Spanish reports are welcome.

| You need to…                                                 | Use…                                                                                                                        |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| Ask how to investigate a codebase or choose a starting point | [GitHub Discussions](https://github.com/VillaforTech/trama/discussions)                                                     |
| Report a broken workflow or lost progress                    | [Bug report](https://github.com/VillaforTech/trama/issues/new?template=bug_report.yml)                                      |
| Report a missing or misleading graph relationship            | [Map report](https://github.com/VillaforTech/trama/issues/new?template=map_report.yml)                                      |
| Propose an improvement                                       | [Feature request](https://github.com/VillaforTech/trama/issues/new?template=feature_request.yml)                            |
| Report a vulnerability or exposed credential                 | [Private security report](https://github.com/VillaforTech/trama/security/advisories/new) and [security policy](SECURITY.md) |

Use the smallest public or synthetic example that reproduces the problem. Include the Trama version or commit, operating system, source type, expected result, and observed behavior. For a map issue, include the import or declaration that should support the relationship, plus whether the problem concerns indexing, grouping, filtering, or rendering.

Do not upload private repository contents, access tokens, exported investigations, or personal learning notes to a public issue. A screenshot can expose code and file paths; inspect it before sharing. Maintainers may request a smaller synthetic reproduction when they cannot access an organization's source.

Trama is an early open-source project maintained on a best-effort basis. There is no guaranteed response time or commercial support agreement.
